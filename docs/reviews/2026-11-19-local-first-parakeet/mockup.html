Local transcription ready · works offline

Runs on this computer. Free, private, no API key. Pick the model new transcripts use.

Language check is on. Before using Parakeet, anyscribe listens to the first 30 seconds (under a second, using a 75 MB helper). If the audio isn't one of Parakeet's 25 languages, it uses Whisper Large v3 Turbo instead and says so on the transcript. If Turbo isn't downloaded yet, it stops and offers the download rather than writing gibberish.

How should anyscribe transcribe?

You can change this any time in Settings.

On this computer recommended

Free and private. No account, no API key, works offline. Downloads Parakeet v3 (670 MB) once. About 10 minutes per hour of audio on a typical desktop.

With a cloud service

Slightly more accurate on hard audio, adds speaker labels, very fast. Needs an API key from ElevenLabs, Deepgram, OpenAI, Groq or others. Paid per minute.
